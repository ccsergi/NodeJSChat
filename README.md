# NodeJSChat

A real-time chat application where users interact with ChatGPT using the OpenAI API. This project utilizes **Node.js** for the backend, **Socket.io** for real-time communication, **Express.js** for routing, and **MongoDB** for managing user and message storage. The application is deployed in a **Docker container**, ensuring easy deployment and scalability.

## Features

- Real-time messaging with **Socket.io**.
- Interaction with **ChatGPT** through the **OpenAI API**.
- User authentication and management.
- **MongoDB** for storing users and chat messages.
- **Express.js** for routing.
- Docker containerization for easy deployment and scalability.
